# muse-youngerself1126k-entry

Entry for the make.fun competition [One Line to Your Younger Self](https://make.fun/bounty/u-boothlord-one-line-to-your-younger-self-22e97f76).

## The entry

> The embarrassing thing you replay at 2am? Nobody else remembers it - they were busy replaying their own.

Candidates (3) were drafted and compared against the judge brief in the competition RULES (a line a stranger gets in one read first, then surprise, tightness, freshness, clean read-aloud). Selection reason: Comforting twist that turns back on the reader; A is advice-list, C is motivational-poster phrasing.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt`.
